## Блоки интерфейса (для прохода по компонентам)

1. Header: логотип «Красная Поляна | Купонная книга» + телефон
2. Карточка книги: фото, H1, бейдж статуса («Действует, ещё 9 дней» / «Аннулирована 1 ноября»), ссылка «Скачать PDF», описание, Descriptions (Гость/Даты/Гости/Выдана), прогресс «Использовано N из M кодов» (сегментированный), Alert об аннулировании
3. Секция «Купоны»: H2, подсказка, фильтры-чипсы с каунтерами (Все 2 / SPA и бани 1 / …)
4. Карточка купона: цветная шапка с категорией и способом предъявления (QR-код / Через турникет), заголовок, описание + «Подробнее», цена/условие, место предъявления с иконкой, разделитель, «12 кодов на всех» + иконки людей, кнопка «Показать»
5. Группы «Использованные N» / «Аннулированы N» — collapsible, карточки со статусом (✓ Использован дата / ⊘ Аннулирован), строка «Код — использован/аннулирован», цена с зачёркнутым старым значением
6. Модалка QR: тёмная шапка «Код 1 из 12», название, прогресс-точки, QR, номер кода, бейдж времени/гостя, подсказка, кнопки Назад/Следующий
7. Footer тёмный: «Вопросы по книге» телефон, email, копирайт
