# Купонная книга «Красной Поляны» — прототипы

Редизайн купонной книги на дизайн-системе KP UI 5.24. Здесь лежат HTML-прототипы и документ с решениями.

Репозиторий закрытый: в файлы встроены лицензионные шрифты Halvar и фото курорта.

## Страницы

| Страница | Где открыть |
| --- | --- |
| Книга гостя | `coupon-book-prototype.html` |
| Список выданных купонов | `coupon-book-admin.html`, раздел «Выданные купоны» |
| Шаблон книги в админке | `coupon-book-admin.html`, раздел «Шаблоны книг» |
| Шаблон купона в админке | `coupon-book-admin.html`, раздел «Шаблоны купонов» |

Оба файла открываются двойным кликом, интернет не нужен. В книге гостя сверху есть переключатели: сценарий «Действует / Аннулирована» и вид «Десктоп / Телефон».

## Что в папке

| Файл | Что это |
| --- | --- |
| `coupon-book-prototype.html`, `coupon-book-admin.html` | Готовые страницы, их можно пересылать |
| `prototype.html`, `admin.html` | Исходники страниц |
| `build.py` | Сборка готовых страниц из исходников |
| `img/`, `vendor/` | Фото, логотип и библиотека QR, которые сборка встраивает внутрь |
| `Design.md` | Переменные KP UI, структура экранов, правила и принятые решения |
| `tokens/` | Выгрузка переменных KP UI из Figma |

## Как править

Меняйте `prototype.html` или `admin.html`, затем пересоберите:

```bash
python3 build.py
```

Админка берёт шрифты, токены, типограф и рисунок QR из `prototype.html`, поэтому их меняйте там.

## Правила вёрстки

- отступы только 16 / 24 / 32, скругление карточек 24;
- текст не мельче 14;
- изображения 4:3;
- без висячих предлогов;
- фирменный QR перед запуском нужно проверить на турникетах и кассовых сканерах.

Подробности — в `Design.md`.
