# Купонная книга «Красной Поляны» — прототипы

Редизайн купонной книги на дизайн-системе KP UI 5.24. Здесь лежат HTML-прототипы и документ с решениями.

Репозиторий закрытый: в файлы встроены лицензионные шрифты Halvar и фото курорта.

## Страницы

| Файл | Страница |
| --- | --- |
| `guest-book.html` | Книга гостя |
| `admin-coupons.html` | Админка: список выданных купонов |
| `admin-book-template.html` | Админка: шаблон книги |
| `admin-coupon-template.html` | Админка: шаблон купона |

Каждая страница — один файл. Он открывается двойным кликом, интернет не нужен, его можно переслать отдельно. Страницы админки связаны боковым меню: если три файла лежат рядом, меню ведёт из одного в другой.

В книге гостя сверху есть переключатели: сценарий «Действует / Аннулирована» и вид «Десктоп / Телефон».

## Что ещё в папке

| Где | Что это |
| --- | --- |
| `Design.md` | Переменные KP UI, структура экранов, правила и принятые решения |
| `src/guest-book.html` | Исходник книги гостя |
| `src/admin.html` | Исходник админки, из него собираются все три её страницы |
| `src/img/`, `src/vendor/` | Фото, логотип и библиотека QR, которые сборка встраивает в страницы |
| `build.py` | Сборка страниц из исходников |
| `tokens/` | Выгрузка переменных KP UI из Figma |

## Как править

Меняйте файлы в `src/`, затем пересоберите страницы:

```bash
python3 build.py
```

Админка берёт шрифты, токены, типограф и рисунок QR из `src/guest-book.html`, поэтому их меняйте там.

## Правила вёрстки

- отступы только 16 / 24 / 32, скругление карточек 24;
- текст не мельче 14;
- изображения 4:3;
- без висячих предлогов;
- фирменный QR перед запуском нужно проверить на турникетах и кассовых сканерах.

Подробности — в `Design.md`.
