# Купонная книга «Красной Поляны» — прототипы

Редизайн купонной книги на дизайн-системе KP UI 5.24. Здесь лежат HTML-прототипы и документ с решениями.

Репозиторий закрытый: в файлы встроены лицензионные шрифты Halvar и фото курорта.

## Что открыть

| Файл | Что это |
| --- | --- |
| `coupon-book-prototype.html` | Книга гостя. Один файл, открывается двойным кликом, интернет не нужен |
| `coupon-book-admin.html` | Админка: «Выданные купоны», редактор шаблона книги и редактор шаблона купона. Тоже один файл |
| `Design.md` | Переменные KP UI, структура экранов, правила и принятые решения |
| `wireframe.html` | Ранний вайрфрейм книги гостя, оставлен для истории |

В книге гостя сверху есть переключатели: сценарий «Действует / Аннулирована» и вид «Десктоп / Телефон».

## Как править

Исходники — `prototype.html` (книга гостя) и `admin.html` (админка). После правок пересоберите файлы:

```bash
python3 build.py
```

Сборка встраивает внутрь фото из `img/`, логотип, шрифты и библиотеку QR из `vendor/`. Админка берёт шрифты, токены, типограф и рисунок QR из `prototype.html`, поэтому сначала меняйте их там.

## Правила вёрстки

- отступы только 16 / 24 / 32, скругление карточек 24;
- текст не мельче 14;
- изображения 4:3;
- без висячих предлогов;
- фирменный QR перед запуском нужно проверить на турникетах и кассовых сканерах.

Подробности — в `Design.md`.
